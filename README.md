# Al Jefoon Tents — Customer Accounts

GitHub Pages-ready customer accounts application.

Features: customer opening balances, receivables/credits, sales, payments, optional fields, edit/delete, notes, cash/bank/BOTIM/cheque payments, cheque number/bank/date/clearance fields, customer statements, multi-customer A4 printing, reports, CSV export, JSON backup/restore, dark mode, and UAE digital clock.

## GitHub Pages
Upload the files while preserving the `css` and `js` folders. In GitHub: Settings → Pages → Deploy from branch → choose your main branch and root folder.
